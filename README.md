本目录为投稿稿件的**可复现分析资产**（对应 Declarations · "Code and reproducibility"）。

## 快速开始（开箱即用）

**本包克隆到任意机器、任意目录后可直接运行，不需要修改任何脚本中的路径。** 所有脚本通过 `code/_paths.py` 取路径，该模块以**自身文件位置**推断仓库根目录。

```bash
git clone https://github.com/kongtonglangke/-igan-gdiga1-axis-pipeline-.git
cd -igan-gdiga1-axis-pipeline-
python code/_paths.py      # 自检：打印各根目录及存在性；退出码 = 问题数（正常为 0）
```

目录契约（脚本自动识别，无需配置）：

| 变量 | 含义 | 来源 |
|---|---|---|
| `REPO` | 仓库根（含 `code/`、`data/`、`results/`） | 自动推断 |
| `DATA` / `RESULTS` | 各证据层**处理后结果表** / 分析产出 | **随仓库分发** |
| `LIB` | `code/lib/`，随包第三方辅助模块 | **随仓库分发** |
| `RAWDATA` | 外部原始数据根（原分析的 `00_rawdata/`） | **需自行下载**（见论文 Data Availability 所列 accession） |
| `SUBMISSION` | 投稿材料目录 | **不随仓库分发**；仅 `code/review_cleanup_*` 审计脚本使用 |

三个环境变量可覆盖上述推断（优先级最高；不设即自动推断）：

```bash
export IGAN_REPRO_ROOT=/path/to/-igan-gdiga1-axis-pipeline-    # 仓库根
export IGAN_RAWDATA_ROOT=/path/to/00_rawdata                # 外部原始数据根
export IGAN_SUBMISSION_DIR=/path/to/submission              # 投稿材料目录（一般无需设置）
```

`RAWDATA` 默认查找顺序：`$IGAN_RAWDATA_ROOT` → `<REPO>/00_rawdata` → `<REPO>/rawdata` → `<REPO>/../00_rawdata` → `<REPO>/../rawdata`。把原始的 `00_rawdata/` 放在仓库同级目录即可，不必设变量。

四点说明：

- `code/lib/tabix_remote.py` 为**随包分发**的第三方辅助模块（纯 Python BGZF/tabix 区域读取），`code/M2_lead_eqtl/stepA_fetch_regions.py` 与 `code/M2b_susie_coloc/fetch_chr1_17.py` 依赖它。
- `.tbi` 索引属第三方文件、不随包分发：上述两个脚本在索引缺失时**自动**从 eQTL Catalogue 下载到 `$RAWDATA/eQTL_Catalogue/tbi/`。
- **CollecTRI（OmniPath）**同属第三方、不随包分发：`code/lib/collectri.py` 在文件缺失时**自动**从 OmniPath 下载（落 `data/sc_regulatory/raw_cache/`，见下文「CollecTRI 版本说明」）；`code/sc_regulatory/step0_build_cache.py` / `step2_regulon.py` 已接入该逻辑。
- `code/review_cleanup_2026-09-10/` 下的少量审计脚本引用了原工程树中**未分发**的路径（`阶段4/初稿/`、投稿件等）。它们属**整改留痕、不参与分析流程**，在纯克隆环境中无法运行；其余脚本不受影响。

## CollecTRI 版本说明（重要）

CollecTRI 是 OmniPath 的 TF–靶基因资源，属**持续更新的活资源**，OmniPath 未提供"按版本固定下载"的入口；而本仓库分析所用的那份文件**不随仓库重分发**（见 License 段）。因此 `code/lib/collectri.py` 在自动获取时会做版本校验，并在结果与论文所用网络不一致时**显著打印告警**（不中断、更不静默通过）。

**2026-10-01 起，本分析所用的网络已由「一次中断下载所得的截断快照」更换为完整的 CollecTRI 网络**（作者决策「方案 B／采用完整网络」），全部下游结果（step2/step3、Table S9/S10、Fig. S6、正文 R9 层）均已在完整网络上**重跑**，论文报告的就是下表第一行的结果。

| | 记录数 | 规范化 md5 | 合格 regulon 口径与数量 |
|---|---|---|---|
| **本分析现行所用（完整网络）** —— `step2_regulon.py`、Table S10、Fig. S6、正文 R9 层 | **64,516** | `9296d2eb6f687dafe4067c233d5330d4` | 调控子 **1,201**、不同靶基因 **6,628**；表达面板 8,248 基因内、`min_targets=5`、**不限上限** → **778** |
| **已退役的历史快照**（旧版 Table S10 / Fig. S6 / R9 层所用；**不回改**，见下） | 16,236 | `857151b015c24a1fe180bcc323162e46` | 截断快照（仅完整网络的约 25%、682 个 TF）；旧口径 `min_targets=5 / max_targets=500` → **317** |

**结论**：在线自动获取到的文件即当前应使用的版本（校验和相符时 `code/lib/collectri.py` 直接放行并在日志中标示 `snapshot?  : True`）。**只有一种版本会被放行**——论文所用完整网络；若取回的文件与之不符，模块会显著告警并列出对 regulon 集合与 Table S10 / Fig. S6 数值的影响，不做静默替换。

> **来源与形态说明**：完整网络从 OmniPath 的 CollecTRI 查询接口取回：`https://omnipathdb.org/interactions?datasets=collectri&genesymbols=1&format=tsv`（`genesymbols=1` 为**必需参数**，缺它时不返回 `source_genesymbol`/`target_genesymbol` 两列）。**历史快照的留档位置（包外，供审计）**：`阶段4.5_复现包/_planB_work/before_planB_20261001/CollecTRI_omnipath.tsv`（1,066,488 B）—— 该文件是**一次中断的下载**，有效内容为表头 ＋ 16,236 条完整记录，末尾另有一行在词中间被截断的残缺记录（`O95644\tP12883\tNFATC1\tMYH7\tTru`，`True` 少一个 `e`，且文件不以换行结尾）；`code/lib/collectri.py` 在统计时自动丢弃不完整末行，`step2_regulon.py` 的 `dropna()` 亦使其不影响 regulon 构建。**按「历史快照不回改」，基于该快照得出的旧数值只在本文件的版本记录中留痕，不替换现行 Table S10 / Fig. S6 / 正文。**

## 运行环境（原分析）

- 主图渲染：专用 Python 环境（fig43 venv，项目工作树内），依赖 matplotlib、numpy、scipy、pandas 等；各 `fig_scripts/*_render.py` 顶部注释含输出路径与用法，`OUT_STEM` 可覆盖（默认与冻结件一致）。
- M1 差异表达：limma 流程见 `M1_geo/step3_limma_R.R`（R ≥ 4.x）；其余步骤 Python 3。
- 外部数据下载/查询脚本需要网络访问相应公共资源（eQTL Catalogue、GoDMC API、GWAS Catalog、NCBI GEO）。
- `00_rawdata` 原样下载缓存**不随本包分发**（体积/许可），由下载脚本与 accession 重建。
- 单细胞调控子推断的环境：独立 venv（numpy 2.5.3 / scipy / pandas / statsmodels 0.15 / scikit-learn）。
- **2026-09-10 重跑记录**：`step2_regulon.py --k-null 1000`（原 200）——经验零分布由 200 组目标数匹配随机基因集提升到 **1,000 组**，使经验 P 脱离 1/K 分辨率下限；**通过集合不变（36 / 950，3.8%）**，DNMT1 0.010→0.025、KLF2 0.005→0.006、SP1 0.015→0.019；下游 step3 交集因子随之由 TFAP2A 变为 **MYC**（ch4 R8 与 Fig. S6 已同步）。脚本新增 `--k-null` 参数（默认 1,000），`step2_summary.json` 记录 `k_null`。
  > **（已被取代 · 2026-10-01）** 上行为**截断快照（317 regulon）口径**下的记录，随作者决策「方案 B／采用完整网络」重跑而作废：现行口径为 **778** regulon、零分布**按各调控子自身靶数匹配**（`--k-null` 仍 1,000/档），经验显著数为 **84 / 2,334（3.6%）**、BH-FDR 后**仅 ERF 存活**；step3 基序命中与经验显著集**交集为空**，故改为**容忍性事后清单**（emp P<0.05 或 top40，共 14 因子，ASCL1/E2F6/ETV6/FOXA2/HOXA9/MYC/MYCN/SMAD3/SNAI1/SP2/SP3/TCF12/TCF3/ZNF148），该层结论由阳性改为**阴性**（正文 R9、Fig. S6、Table S10 已同步）。**按「带日期的历史记录不回改」保留上行原文，仅在其后追加本说明；现行数值见本文件版本记录 v2.15。**
